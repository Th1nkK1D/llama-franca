# Agent guidelines

## Files

- Always name files in kebab-case, including Svelte components, e.g. `selection-popover.svelte`, `app.svelte`

## Commits

- Single-line [Conventional Commits](https://www.conventionalcommits.org) subject, e.g. `feat: add language picker`, `fix: reset session on navigation`, `chore: bump deps`
- No commit body
